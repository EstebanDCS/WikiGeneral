# Prácticas — Sistemas de Información

## Proyecto

Desarrollo de un sistema de gestión de **carreras populares** (inscripción, pago, cronometraje, resultados) usando **Scrum** con 3 sprints.

---

## Estructura del proyecto

| Sprint | Contenido |
|--------|-----------|
| **Sprint 1** | HUs proporcionadas por el profesor → implementar y probar |
| **Sprint 2** | Elaborar HUs del siguiente módulo + implementar + pruebas |
| **Sprint 3** | Elaborar HUs restantes + implementar + pruebas + presentación |

---

## Guías de prácticas

- [[Git-y-Pull-Requests]] — flujo Git/GitHub, Pull Requests, revisión de código

---

## Evaluación

- Evaluación continua de cada sprint.
- Entrega de las prácticas.
- Presentación final del proyecto.

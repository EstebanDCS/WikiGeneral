## Summary

Tema 2.2 de Sistemas Inteligentes. Cubre las técnicas para evaluar modelos de forma realista: resustitución (incorrecta), hold-out, validación cruzada y meta-validación. También trata cómo aplicar normalización/estandarización correctamente dentro del esquema de validación.

## Key Points

- **Resustitución**: entrenar y evaluar con los mismos datos → evaluación muy optimista, NO válida
- **Hold-out**: dividir en train (80%) y test (20%); adecuado para datasets grandes
- **Validación cruzada (K-fold)**: dividir en K grupos; K entrenamientos, cada uno evalúa en un grupo diferente; resultado = media de K evaluaciones
- **Meta-validación**: train + dev + test; dev para ajustar hiperparámetros, test para evaluación final
- **Normalización con validación**: los parámetros (media, desviación, mín, máx) se calculan SOLO con train; luego se aplican a train y test

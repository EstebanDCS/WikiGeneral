## Summary

Primera práctica de redes neuronales con Keras/TensorFlow. Resuelve el mismo problema de regresión de P3.2 (Sector1Time → LapTime) para comparar con modelos clásicos. Enseña el flujo completo: crear arquitectura Sequential, compilar, entrenar con `.fit()`, ajustar hiperparámetros (learning rate), añadir no linealidad (capa oculta con tanh).

## Key Points

- **Librería**: `tensorflow` con la API de alto nivel `keras`
- **Modelo Sequential**: capas añadidas una tras otra con `.add()` o lista
- **Capas**: `Input(shape=(...))` para definir la entrada, `Dense(n)` para capa fully connected
- **Compilar**: especificar `optimizer` (ej: `'adam'`), `loss` (ej: `'mae'`) y `metrics`
- **Entrenar**: `.fit(X_train, Y_train, epochs=N, batch_size=M, validation_split=0.1)`
- **Cada vez que se ejecuta `.fit()` continúa desde donde estaba** — para reiniciar hay que recrear el modelo
- **Ajuste de learning rate**: probar 0.001, 0.05, 0.1 — más alto converge más rápido pero puede no converger
- **No linealidad**: añadir capa oculta con activación `tanh` permite aprender relaciones no lineales
- **Entrenamiento en GPU**: en los ordenadores de prácticas disponible; en PC personal solo CPU

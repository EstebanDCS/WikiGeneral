## Summary

Práctica de visualización de datos sobre el dataset F1 Monaco 2023. Cubre visualización estática (Matplotlib + Seaborn) y dinámica (Bokeh). Incluye distribuciones, relaciones, múltiples variables, mapas de calor y reducción de dimensionalidad (PCA + t-SNE) para visualizar.

## Key Points

- **Matplotlib**: librería base de visualización en Python
- **Seaborn**: interfaz de alto nivel sobre Matplotlib; simplifica gráficos comunes
- **Bokeh**: genera gráficos HTML interactivos (se pueden manipular tras generarlos)
- **Distribuciones**: `sns.histplot`, `sns.countplot`, `sns.kdeplot`
- **Relaciones**: `sns.barplot`, `sns.lineplot`, `sns.scatterplot`, `sns.regplot` (con línea de tendencia)
- **Múltiples variables**: color/forma para una variable extra, `sns.pairplot`, scatter 3D con `mpl_toolkits`
- **Mapas de calor**: `sns.heatmap` sobre una `pivot_table`
- **Reducción + visualización**: PCA y t-SNE de sklearn para visualizar 6 variables en 2D

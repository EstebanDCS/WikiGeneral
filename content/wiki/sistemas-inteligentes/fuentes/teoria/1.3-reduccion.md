## Summary

Tema 1.3 de Sistemas Inteligentes. Presenta el problema de la alta dimensionalidad y las técnicas para reducirla. Se estudian en profundidad PCA y t-SNE, con sus fundamentos, limitaciones y casos de uso, y se presentan brevemente otras técnicas (ICA, LDA, NMF, Autoencoders). El tema concluye con aplicaciones reales: visualización, eliminación de características irrelevantes y compresión de datos.

## Key Points

- **Dimensionalidad** = número de variables/características de un dataset; tiende a crecer (imágenes = píxeles, genes, sensores...)
- **PCA**: combinaciones lineales que maximizan la varianza. Siempre obtiene tantas PC como dimensiones originales; luego selecciona las N mejores. Métrica: varianza explicada. **No funciona bien con datos no linealmente separables**.
- **t-SNE**: reducción no lineal, optimizada para 2D. Usa perplejidad para escalar distancias. Las dimensiones resultantes no tienen significado; solo importa la proximidad local.
- **Combinación PCA + t-SNE**: primero PCA reduce ruido y dimensiones, luego t-SNE optimiza para 2D.
- **LDA**: supervisado (necesita etiquetas). Separa clases maximizando la distancia entre ellas y minimizando la dispersión interna.
- Aplicaciones: visualización de datos de alta dimensión, eliminar características irrelevantes por varianza explicada, compresión (autoencoders)
